Jam Detection Logic

How FillPac AI classifies conveyor motion

1. Track Bag ByteTrack associates the same bag across frames.
2. Measure Movement Center (x, y) movement is measured using Euclidean distance.
3. Calculate Speed Pixel distance divided by elapsed time gives motion in px/s.
4. Classify State NORMAL → SLOW → WARNING → JAM → RECOVERING.
